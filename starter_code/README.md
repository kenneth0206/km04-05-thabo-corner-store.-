2. Create a virtual environment (recommended):
   ```bash
   python3 -m venv venv

   ```
3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
4. Copy the `data/` folder (provided separately) so it sits **next to**

Data Cleaning Decisions:
During the data cleaning process, the products dataset was reviewed and cleaned by removing duplicate records and removing products that had missing product names, as these records could not be reliably used in the analysis. Missing unit prices were filled using the average unit price to maintain consistency in the dataset, and category names were standardised using Title Case to ensure uniform formatting.The sales dataset was also cleaned by removing duplicate records and standardising all dates into the YYYY-MM-DD format. Records with missing or invalid sale dates were removed because they could not be used for sales trend analysis. Missing quantities were replaced with a value of 1, while missing payment methods were replaced with "Unknown" to avoid making assumptions about the original payment method. Sales records that referenced invalid product IDs were removed to maintain data integrity. As a results of the cleaning process, the products dataset was reduced from 16 raw to clean records to 14 clean records, while the sales dataset was reduced from 71 raw records to 53 clean records.

1. Project Overview
- This project focuses on developing a sales insights system for Thabos's Corner Store. The system uses Python, sqlite and data visualisation to analyse sales information and help the store make better business decisions.

2. Database and SQL Queries 
- A SQLITE database called store.db was created to store the cleaned product and sales data. Two tables were created:product and sales. The products table stores product information, while the sales tables stores transaction information. Primary keys and foreign keys were used to connect the tables and maintain data accuracy.
- Five SQL queries were developed to analyse total revenue per product, the best-selling product, sales by payment method, revenue by category and sales by customer type.

3. Python Analysis
- Python functions, loops and conditional statements were used to analyse the sales data.

- The analysis included counting sales records, identifying products that need restocking, calculating monthly sales trends, classifying transactions sizes and calculating the average basket size.

4. Data Visualisation
- Tow charts were created using Matplotlib.
- The first chart shows total revenue generated by each product. The second chart shows the monthly sales trend.

- These charts make it easier to understand product performance and changes in sales over time.

5. Security

- A password protection system was implemented using Pythons' hashlib library and SHA-256 hashing.

- The system require users to enter a password before accessing the sales reports. Password are stored as hashes instead of plain text.
- Confidentiality is supported through password protection. Integrity is supported through database keys and relationships. Availability can be improved by keeping regular backups of the database.

6. Business Insights
- The analysis showed that 5Kg Maize Meal generated the highest revenue at approximately R801, followed by Lays Chips 100g and Eggs(6pack).
- These products should be prioritised when planning stock levels to avoid losing sales opportunities.
- Some products generated lower revenue and may benefit from promotions.

- The monthly sales chart also showed changes in sales quantities over time. This information can help the store improve stock planning and make better business decisions.
